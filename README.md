# dart_reporting

A static analysis and code audit CLI tool for Dart/Flutter projects. Acts as a custom alternative to SonarQube, designed to run in CI pipelines (GitHub Actions) and generate standardized SARIF reports.

## Features

### 1. AST Analysis Engine (`lib/src/analyzer/`)
- **Memory Leaks:** Detects `StreamSubscription` and `Timer` fields not cancelled in `dispose()` of `StatefulWidget`.
- **Render Performance:** Recommends `MediaQuery.sizeOf(context)` over `MediaQuery.of(context)`.
- **Data Consumption:** Detects `Image.network()` and recommends `cached_network_image`.
- **Const Widgets:** Suggests `const` constructors for widgets like `SizedBox()`, `Spacer()`, `Divider()`.

### 2. Code Duplication Detection (`lib/src/ast_duplication/`)
- Structural AST-based analysis (alpha-equivalence).
- Ignores variable names, formatting, and whitespace.
- Produces SHA-256 hashes for structural comparison.
- Reports exact duplication percentage (technical debt metric).

### 3. LCOV Coverage Parser (`lib/src/lcov_parser/`)
- Parses `coverage/lcov.info` files generated by `flutter test --coverage`.
- Filters out auto-generated files (`*.g.dart`, `*.freezed.dart`, etc.).
- Configurable minimum coverage threshold.

### 4. Security Audit (`lib/src/security_osv/`)
- Parses `pubspec.lock` to extract dependency information.
- Queries the [OSV](https://osv.dev/) vulnerability database for known CVEs.
- Checks [pub.dev](https://pub.dev/) for discontinued packages.

### 5. SARIF Report Generator (`lib/src/sarif_exporter/`)
- Generates SARIF v2.1.0 compliant JSON reports.
- Compatible with GitHub Code Scanning (upload via `github/codeql-action/upload-sarif@v3`).

## Installation

Add to your project's `dev_dependencies`:

```yaml
dev_dependencies:
  dart_reporting:
    git:
      url: https://github.com/Thematt69/dart_reporting
```

## Usage

```bash
# Run full analysis
dart run dart_reporting

# Customize options
dart run dart_reporting \
  --project . \
  --output report.sarif \
  --lcov coverage/lcov.info \
  --min-coverage 80 \
  --skip-security

# Show help
dart run dart_reporting --help
```

## GitHub Actions Integration

See `.github/workflows/analysis.yml` for a complete workflow template. Key steps:

```yaml
- name: Run dart_reporting analysis
  run: dart run dart_reporting --output dart_reporting.sarif

- name: Upload SARIF to GitHub Security
  uses: github/codeql-action/upload-sarif@v3
  with:
    sarif_file: dart_reporting.sarif
```

```
    │   ├── duplication_models.dart

    │   ├── finding.dart

    ├── lcov_parser/             # LCOV coverage parser
    │   ├── lcov_module.dart
    │   ├── lcov_models.dart
    │   └── lcov_parser.dart
    ├── sarif_exporter/          # SARIF report generator
    │   └── sarif_exporter.dart
    └── security_osv/            # Security audit
        ├── osv_client.dart
        ├── pub_dev_client.dart
        ├── pubspec_lock_parser.dart
        └── security_module.dart
```
